# Projeto DevOps Study

Projeto feito para iniciar os estudos em DevOps.

## Objetivo

Este repositório foi criado com o objetivo de praticar conceitos e ferramentas relacionadas a DevOps, como:

- Infraestrutura como Código (IaC)
- Automação com Ansible
- Provisionamento com Terraform
- AWS

## Tecnologias

- Terraform
- Ansible
- AWS
- Linux
